# Observer

Observer наблюдает за видимым окном ArcheAge на Windows 11 и отправляет сообщения в Discord, когда замечает движение или теряет обзор. Приложение анализирует изображение примерно раз в секунду, обводит найденную область на снимке и подавляет повторные уведомления об одном стоящем объекте.

**Состояние проекта:** версия 1 обнаруживает движение, но пока не определяет, является ли объект трактором, галеоном или фрегатом. Для такой классификации нужны игровые кадры. Требования к следующей версии описаны в [плане 2.0](docs/V2_PLAN.md).

## Установка

Готовый архив [Observer-win-x64.zip](https://github.com/sheezeeq/Observer/releases/tag/v0.1.0) доступен в разделе **Releases**. Распакуйте его и запустите `Observer.exe`; установка .NET не требуется. Новые сборки также появляются как артефакты на вкладке **Actions**.

Либо соберите проект самостоятельно с помощью .NET 10 SDK на Windows:

```powershell
dotnet publish Observer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist
```

## Настройка

1. Запустите ArcheAge в оконном режиме. Окно должно оставаться видимым и на переднем плане.
2. Создайте вебхук нужного канала Discord, вставьте его адрес в Observer и нажмите **Проверить Discord**.
3. Выберите окно ArcheAge, нажмите **Обновить снимок** и выделите мышью область наблюдения. Лучше исключить чат, интерфейс и анимированные области, которые не относятся к маршруту транспорта.
4. Нажмите **Начать наблюдение**. Observer свернётся и вернёт фокус игре. Для остановки откройте его с панели задач.

Если обзор нарушен более 15 секунд, Observer сообщает об этом. При полностью неподвижном изображении сигнал появляется через 90 секунд. Неотправленные сообщения хранятся в очереди и повторно отправляются после восстановления связи.

Данные приложения находятся в `%LOCALAPPDATA%\Observer`: настройки, до 100 снимков событий и очередь до 50 сообщений. Адрес вебхука сохраняется с защитой Windows для текущей учётной записи, если Windows разрешает это сделать.

## Ограничения и проверка

- Возможны ложные срабатывания на игроков, эффекты, воду и другие движущиеся области.
- Полноэкранный и безрамочный режимы пока не поддерживаются. Свёрнутая игра не даёт пригодного изображения для наблюдения.
- Сборка прошла; синтетический сценарий подтвердил одно уведомление при движении без повторов во время стоянки и сохранение очереди. Проверка на живой ArcheAge и реальном вебхуке ещё не проводилась.
- Приложение анализирует видимые пиксели, не читает память игры и не отправляет игровые команды.

Адрес вебхука даёт право отправлять сообщения в канал Discord. Не публикуйте его и не добавляйте `settings.json` в Git.
